# ODEAction

Project webpage for **ODEAction: From Predicting Chunks to Evolving Actions**.

- [English](https://wang-qishen.github.io/odeaction-website/)
- [中文](https://wang-qishen.github.io/odeaction-website/zh.html)
- [Paper](https://arxiv.org/abs/2611.09672)
- [Code](https://github.com/OpenHelix-Team/ODEAction)
- [Video](https://wang-qishen.github.io/odeaction-website/video/)

This repository contains the static bilingual research webpage, interactive illustrations, figures, and paper PDF. GitHub Pages serves the repository root from the `main` branch.

To preview locally, run `python3 -m http.server 8000` in this directory.
